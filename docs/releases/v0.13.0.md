---
title: lok8s v0.13.0
---

This release fixes a Go standard library vulnerability in `lo mcp serve`.
It also ships the changes merged since [v0.12.0](./v0.12.0.md).

## Security

- **GO-2026-6859** (CVE-2026-97054, `net/http`). An HTTP/1 server that uses
  `http.MaxBytesReader` can panic when its handler reads the request body
  while it writes the response header. `lo mcp serve` (alias
  `lo mcp stream`) serves the MCP streamable HTTP handler, which wraps each
  request body in `MaxBytesReader`. A request body above its limit (4 MiB by
  default) can crash the server. The server listens on `127.0.0.1` by
  default. With `--host`, other machines can reach it. `lo` is now built
  with Go 1.26.11, which fixes it (#336). The other `lo` commands use
  `net/http` as a client only.
- `github.com/klauspost/compress` v1.20.2, for GO-2026-6865 (#330).
- `golang.org/x/crypto` v0.58.0 (#286, #289) and `google.golang.org/grpc`
  v1.83.2 (#331). The docs site takes `source-map-js` 1.2.2
  (GHSA-68fv-2mgg-jv7q, #321).

## Changes

- The sso-gate addon asks the issuer for `offline_access` (#243). Envoy
  Gateway then renews a session with the refresh token when the access
  token expires, for up to one week by default (`defaultRefreshTokenTTL`).
  A sign-out at the issuer does not end that session.
  `docs/guide/addons.md` says how to end one.
- `lo kubehz node cordon`, `uncordon` and `drain` for the nodes of a Space
  (#334).
- The kind node-IP repair also renews the apiserver certificate of a
  control-plane node. Before, the controller-manager and the scheduler
  could not reach the apiserver after the repair (#328).
- The Ready-timeout hint names an image pull that failed or hangs (#333).
- `lo-install.sh` retries a transient download failure (#329).
- Addons: cilium 1.20.4, which starts on kernel 7.2 (#326); envoy-gateway
  v1.9.3 and cert-manager v1.21.3 (#327).
- The toolchain pins b v4.18.8 (#332).
- Docs: current platform facts and fixed anchors (#324); the first run,
  `lo chat`, the MCP guide and the Go driver contract (#325).
- Tests: no test can fall back to a real cluster through `KUBECONFIG`
  (#319, #323).

## Upgrade

- Update the pins (`lo`, the `kustomize-secret` plugin and the `.lok8s` env
  ref) to `v0.13.0`.
- If you run `lo mcp serve --host` on an address other than loopback,
  upgrade first, or bind it to `127.0.0.1` until you can.
- If you use the sso-gate addon, check two things at your issuer before
  you upgrade. The client needs the refresh-token grant. And the issuer
  must accept `offline_access`: a strict issuer that refuses the scope
  breaks the sign-in, while the policy still shows `Accepted`. To keep
  the old scopes, apply the removal patch from the header of
  `.lok8s/addons/sso-gate/kustomization.yaml` (`docs/guide/addons.md`
  explains it).
- To build from source, you need Go 1.26.11 or later (`go.mod`).
