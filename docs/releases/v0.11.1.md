title: lok8s v0.11.1
---

A version-reference release. The code is the same as in
[v0.11.0](./v0.11.0.md). Read the v0.11.0 notes before you upgrade from
v0.10.x.

## What changed

v0.11.0 shipped with the old version number in these places:

- `.lok8s/VERSION` and `internal/assets/lok8s/VERSION` read `0.10.1`. The
  release binaries reported `0.11.0`, because CI stamps the tag into them. A
  build from the tree (`make build`) and the bash implementation
  (`spec.implementation: bash`) reported `0.10.1`.
- The install commands in the README, the guide and `install/README.md` named
  `v0.10.1`. A copy-paste install got the old release.
- The repo's own `.bin/b.yaml` pinned `lo` at `v0.10.1`.

All of these now read `0.11.1`.

## Upgrade

- From v0.11.0: update the pins (`lo`, the `kustomize-secret` plugin and the
  `.lok8s` env ref) to `v0.11.1`. Nothing else changes.
- From v0.10.x: follow the v0.11.0 notes, then pin `v0.11.1`.
