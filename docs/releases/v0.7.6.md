One fix in the Hetzner provider, no new command and no change to the piped
output of the parity cases.

## Fixed

- A boolean value in a Hetzner server entry is one `hcloud` switch. A key
  such as `without-ipv6: true` used to reach `hcloud server create` as
  `--without-ipv6 true`, a bare flag followed by a stray argument, so a
  server could not be created without public IPv6 from the descriptor. A
  boolean now travels as one `--key=true` / `--key=false` token; every other
  value type is unchanged. Two unit cases pin the shape (#236).

## Why it matters

On a host whose IPv6 path to a registry black-holes, an image pull can sit
on an established but dead connection for minutes while the same pull over
IPv4 takes seconds. `without-ipv6: true` on the server is the way to make
such a host pull over IPv4 only.
